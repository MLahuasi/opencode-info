# Desarrollo asistido y controlado con OpenCode

Repositorio utilizado en los ejemplos: [OpenCode Weather CLI](https://github.com/MLahuasi/opencode-weather-cli-app).

> **Contexto de los ejemplos:** los nombres de archivos, ramas, comandos, configuraciones y decisiones mostrados en este capítulo pertenecen a ejemplos didácticos. Adáptalos al proyecto, la versión de las herramientas y las convenciones que estés utilizando.

> **Nota:** OpenCode puede generar una cantidad considerable de código, configuraciones o funcionalidades que todavía no comprendamos completamente. Cada cambio generado debe revisarse, comprenderse y validarse antes de incorporarlo al proyecto.

Una forma práctica de trabajar con OpenCode consiste en preparar primero el proyecto y su documentación, utilizar `Plan` para diseñar los cambios y posteriormente utilizar `Build` para implementarlos. Al final se validan las pruebas, el versionado y la integración continua.

## Cómo recorrer el temario

Lee primero el documento 1 para preparar el proyecto. Continúa con los documentos 2 y 3 para planificar, implementar y revisar cambios. Después valida el resultado con el documento 4, registra el trabajo siguiendo el documento 5 y automatiza los entregables con el documento 6. Utiliza el documento 7 como resumen y lista de comprobación final.

El capítulo 08 contiene procedimientos detallados para ramas, worktrees, Pull Requests y GitHub Actions. Este capítulo resume únicamente lo necesario para relacionar esas prácticas con el flujo de OpenCode.
