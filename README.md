# Temario: OpenCode, herramientas y desarrollo asistido

Este repositorio reúne guías, conceptos y ejemplos para trabajar con OpenCode. El recorrido cubre la instalación y configuración, el contexto de trabajo, la automatización, Git y GitHub, MCP, agentes y Spec Driven Development (SDD). Los proyectos de ejemplo —incluido el laboratorio OpenDayCare— ilustran la aplicación práctica de esos temas.

## Índice

1. [Preparar el entorno](./temarios/01-preparar-entorno.md) — instalación, terminal y proveedores.
2. [Configuración y uso diario](./temarios/02-configuracion-y-uso-diario.md) — configuración global, contexto y TUI.
3. [Desarrollo, automatización y colaboración](./temarios/03-desarrollo-y-colaboracion.md) — desarrollo asistido, Git, GitHub, MCP, agentes, comandos, LSP, Formatters, subagentes y CRON Jobs.
4. [Metodologías de desarrollo de software](./temarios/04-metodologias-de-desarrollo-de-software.md) — SDD y futuras metodologías como Grill-me y OpenSpec.
5. [Referencias y consulta rápida](./temarios/05-referencias.md) — comandos, modelos y documentación de consulta.
6. [Laboratorio OpenDayCare](./opencode-daycare/README.md) — ejemplos de aplicación de los temas anteriores.

> Los documentos enlazados conservan sus comandos, ejemplos, bloques de código e imágenes. Los submenús organizan la navegación sin duplicar el contenido de las guías.
