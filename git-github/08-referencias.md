## Rutas de configuración en GitHub

```text
settings/installations
```

Permite administrar las aplicaciones instaladas, incluida OpenCode Agent.

```text
settings/secrets/actions
```

Permite configurar los secretos utilizados por GitHub Actions, como `OPENAI_API_KEY`.

```text
/settings → Features → Issues
```

Permite habilitar la función `Issues` en el repositorio.
