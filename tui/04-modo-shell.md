# Modo Shell

> **Ejemplo:** el comando mostrado es ilustrativo. Revisa el comando antes de ejecutarlo y no asumas que la salida será igual en todos los entornos.

Escribe `!` al inicio de un prompt vacío para entrar al modo `shell` y ejecutar un comando:

```text
!node --version
```

La salida del comando se incorpora a la conversación y puede utilizarse como contexto. Por ejemplo, después puedes preguntar qué versión de Node.js se está ejecutando.

Para salir del modo `shell` sin ejecutar el comando, presiona `Esc`.
