# Referencia de atajos

> **Ejemplo:** esta tabla es una referencia orientativa. Los atajos y nombres de comandos pueden variar entre versiones y configuraciones.

| Acción | Comando o atajo |
| --- | --- |
| Mostrar comandos | `Ctrl + P` o `/` |
| Borrar hasta el inicio de la línea | `Ctrl + U` |
| Borrar palabra anterior | `Ctrl + W` |
| Buscar o referenciar archivo | `@archivo` |
| Entrar en Shell | `!` |
| Salir del modo Shell | `Esc` |
| Crear nueva sesión | `/new` o `Ctrl + X`, luego `N` |
| Recuperar sesión anterior al iniciar | `opencode -c` |
| Mostrar sesiones | `Ctrl + X`, luego `L` |
| Renombrar sesión | `Ctrl + R` |
| Mostrar u ocultar barra lateral | `Ctrl + X`, luego `B` |
| Compactar contexto | `/compact` |
| Deshacer | `/undo` o `Ctrl + X`, luego `U` |
| Rehacer | `/redo` o `Ctrl + X`, luego `R` |
| Cambiar entre Plan y Build | `Tab` |
| Generar o actualizar `AGENTS.md` | `/init` |
| Selector de temas | `/theme` o `/themes`, según la versión |

Para conocer los comandos disponibles en tu sesión, escribe `/` o utiliza `Ctrl + P`.
