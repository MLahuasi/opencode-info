# Sesiones y panel lateral

> **Ejemplo:** los atajos mostrados pueden cambiar según la configuración o la versión de la TUI. Verifica la referencia de atajos antes de convertirlos en una instrucción del proyecto.

## 1. Crear una nueva sesión

El comando siguiente crea una nueva sesión:

```text
/new
```

En algunas configuraciones también puede estar disponible `Ctrl + X`, luego `N`.

## 2. Continuar la sesión anterior

Si saliste de OpenCode, puedes intentar recuperar la sesión anterior iniciando OpenCode con:

```bash
opencode -c
```

## 3. Mostrar sesiones anteriores

El atajo siguiente muestra las sesiones anteriores:

```text
Ctrl + X
L
```

Desde esa pantalla puedes seleccionar la sesión que quieres continuar.

## 4. Renombrar la sesión actual

El atajo siguiente permite cambiar el nombre de la sesión actual:

```text
Ctrl + R
```

Los nombres descriptivos facilitan encontrar sesiones posteriormente.

## 5. Abrir y cerrar la barra lateral

El atajo siguiente abre o cierra la barra lateral:

```text
Ctrl + X
B
```

La barra puede mostrar información como:

- Consumo de tokens.
- Costos.
- Contexto utilizado por la sesión.
